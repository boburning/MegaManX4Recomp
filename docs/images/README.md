# Screenshot provenance

All images are unedited captures of the actual runtime or launcher. No mockups
or generated artwork are used. Captures were taken with hidden windows on
2026-10-13; no desktop input or player save files were used.

- `coop-jungle.png`: fresh native co-op Jungle arrival, source matching the
  Playtest 13 gameplay changes. Original framebuffer capture.
- `split-x.png`, `split-zero.png`: composed OpenGL views from the same
  two-peer LAN session after the distant-sprite wrap fix. Positions were set up
  with synchronized development teleports for the regression check.
- `double.png`, `iris.png`: native encounters from the optional consecutive
  story-boss scenario, in X's campaign. Original framebuffer captures.
- `netplay.png`, `coop-options.png`: fresh captures of the packaged Playtest 13
  Windows launcher. The settings screenshot shows an example configuration;
  optional enhancements remain off by default for a new install.
